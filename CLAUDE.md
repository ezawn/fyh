# fyh

Shared repo worked on by several people, each with their own Claude Code session.
Claude sessions on different machines can't message each other, so this repo is how we coordinate.

## Team rules for Claude
- `git pull` before starting work, and pull again before pushing.
- Work on a short-lived branch (`name/feature`), not directly on `main`, once real code exists.
- Commit small and push often so others see progress.
- Never force-push to `main` or rewrite shared history.
- Log what you're doing in `NOTES.md` (who, what, status) and keep it current.
